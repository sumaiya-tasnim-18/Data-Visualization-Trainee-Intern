# Data-Visualization-Trainee-Intern
This repository documents my Data Visualization Trainee Early Internship under "Saint Louis University in USA through "Excelerate" website. Here I worked on auditing, cleaning, analyzing, and visualizing real-world outreach, campaign, and applicant datasets. The internship focused on transforming raw data into structured, insight-driven dashboards to support data-backed decision-making.

# 📇 Internship Overview
    • Datasets: OutreachData.csv, CampaignData.csv, ApplicantData.csv (merged into final master dataset)
    • Final Dataset Size: 39,717 records × 17 columns
    • Tools: Python (Pandas, NumPy, Matplotlib, Seaborn), Excel, Microsoft Power BI, Jupyter Notebook
    • Focus Areas: Data Cleaning, Data Quality Audit, Data Merging, Exploratory Data Analysis (EDA), KPI Development, Dashboard Design, Data Storytelling

# 🗓️ Weekly Tasks Breakdown

    • Week 1: Conducted systematic data quality audit on three raw datasets. Handled missing values, duplicates, invalid IDs, datatype corrections, and inconsistencies. Created cleaned datasets and comprehensive Data Dictionary documentation.
    • Week 2: Merged cleaned datasets into a unified master dataset. Performed Exploratory Data Analysis (EDA), created new feature columns (Month, Weekday, Hour, Is_Response, etc.), analyzed trends, and developed a KPI-driven interactive Power BI dashboard.
    • Week 3: Derived actionable recommendations based on EDA findings. Designed structured presentation slides highlighting outreach performance trends, campaign effectiveness, country-level insights, timing optimization, and operational improvements.
    • Week 4: Finalized presentation deck with strategic recommendations and delivered a data-driven performance briefing. Focused on storytelling, visualization clarity, and converting analytical findings into business decisions.

# 🎯 Outcome
Successfully transformed messy, real-world datasets into structured, analysis-ready data and built an interactive Outreach Campaign Performance Dashboard. The project strengthened hands-on skills in data cleaning, feature engineering, visualization, KPI design, and analytical storytelling using industry-standard tools.
